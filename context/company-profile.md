## Product
TechCorp offers **ProjectFlow** - a cloud-based project management and team collaboration platform designed for small-to-medium businesses (SMBs).

### Key Features
- **Task Management:** Create, assign, and track tasks with Kanban boards and Gantt charts
- **Team Collaboration:** Real-time messaging, file sharing, and comments
- **Time Tracking:** Built-in time tracking with reporting and invoicing
- **Integrations:** Connects with Slack, GitHub, Google Workspace, and Jira
- **Analytics Dashboard:** Real-time metrics on team productivity and project progress
- **API Access:** RESTful API for custom integrations (Enterprise plan only)
